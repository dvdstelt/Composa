# Composa user guide

Composa is a layer-based image editor for compositing and retouching, for Linux and Windows. It is a from-scratch implementation of the macOS app [Compositor](https://github.com/robbietilton/Compositor), with the same tools, adjustments and filters, and it adds one thing of its own: an AI agent can work in it alongside you.

This guide describes what Composa can do and how to do it. It is written for people who use the application; nothing here requires knowing how it is built.

## Conventions

Keys are written for Linux and Windows: Ctrl, Alt and Shift. Menu paths are written as File > Open. Where a dialog or a field has a name, it is quoted as it appears on screen. Sizes are in pixels unless a unit is given.
